Install and configure Laravel packages from a community-driven catalog directly from the CLI.

## Installation

You can install the package via composer:

```bash
composer require cocouvi/xn-orchestrator
```

## Usage

```bash
php artisan xn-orchestrator
```

## Testing

```bash
composer test
```
